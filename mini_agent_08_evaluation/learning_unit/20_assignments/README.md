# 08 Assignment · Mini Agent 최종 점검

지금까지 만든 Mini Agent에 10개 평가 시나리오를 작성하고 반복 실행하세요.

## 필수 시나리오

- 정상 Tool 선택 2개
- Tool이 필요 없는 요청 1개
- 정보 부족 1개
- 잘못된 Tool 인자 1개
- RAG 근거 없음 1개
- 사용자 Memory 격리 1개
- 승인 대기 1개
- 다른 사용자의 승인 차단 1개
- 중복 실행 차단 1개

## 제출 표

| 시나리오 | 기대 Tool | 실제 Tool | 기대 상태 | 실제 상태 | 통과 | 실패 이유 |
|---|---|---|---|---|---|---|

## 실패 분석

실패한 시나리오를 최소 2개 선택하여 다음 내용을 작성합니다.

1. Trace에서 처음 실패한 단계
2. 실제 원인
3. 수정한 코드 또는 정책
4. 수정 뒤 해당 시나리오 결과
5. 기존 시나리오에서 새 회귀가 발생했는지 여부

Provider 비교는 선택 제출입니다. 필수 평가는 Mock 기반으로 반복 가능해야 합니다.
