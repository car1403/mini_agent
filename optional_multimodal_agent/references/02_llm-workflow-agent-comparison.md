# LLM, Workflow, Agent 비교

| 구분 | 적합한 상황 | 예 |
| --- | --- | --- |
| 일반 LLM | 한 번의 생성으로 충분함 | 여행 소개 작성 |
| Workflow | 실행 순서와 규칙이 고정됨 | 입력 검증 후 보고서 생성 |
| Agent | 요청에 따라 도구와 경로를 선택해야 함 | 여행·정책·숙소 문의 라우팅 |

## 선택 기준

고정된 조건문으로 명확하게 해결할 수 있다면 Agent가 필요하지 않을 수 있습니다. Agent를 사용하면 유연성이 커지지만 비용, 지연, 테스트 난이도와 실패 가능성도 증가합니다.

## 역할 분담

```text
LLM
→ 의도 분류, 자연어 추출, 설명 생성

Python
→ 날짜·금액 검증, 권한 검사, 반복 제한, 실제 Tool 실행
```
