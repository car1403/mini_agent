# Agent 보안 기초

## 핵심 원칙

```text
LLM의 실행 제안
≠
시스템의 실행 권한
```

## 필수 기준

- Tool allowlist
- Pydantic 입력 검증
- 사용자별 데이터 격리
- 최대 반복 횟수
- timeout과 retry 제한
- Secret과 개인정보 로그 금지
- 변경 작업 전 Human Approval

## 교육 과정 위험 등급

| 등급 | 예 | 처리 |
| --- | --- | --- |
| 조회 | 날씨·정책 검색 | 자동 허용 |
| 초안 | 일정·예약 요청서 생성 | 자동 허용 |
| 외부 변경 | 예약 요청·메시지 발송 | 승인 후 Mock 실행 |
| 결제·삭제 | 결제, 실제 데이터 삭제 | 과정에서 금지 |
