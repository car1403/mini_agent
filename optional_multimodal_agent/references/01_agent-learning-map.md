# Agent 학습 지도

## 단계별 질문

| 단계 | 핵심 질문 |
| --- | --- |
| LLM | 답변을 생성할 수 있는가? |
| Structured Output | 프로그램이 결과를 안정적으로 사용할 수 있는가? |
| Tool | 외부 데이터나 기능이 필요할 때 무엇을 호출하는가? |
| RAG | 어떤 문서를 근거로 답했는가? |
| Memory | 어떤 사용자 정보를 다음 요청에 사용할 것인가? |
| LangGraph | 어떤 순서와 조건으로 실행할 것인가? |
| Approval | 실행 전에 사용자의 확인이 필요한가? |
| Evaluation | Agent가 올바른 행동을 했는지 어떻게 확인하는가? |

## 누적 여행 예제

```text
여행 요청 분류
→ 여행 조건 추출
→ 날씨·숙소 Tool
→ 정책 RAG
→ 여행 선호 Memory
→ 일정 Workflow
→ 예약 요청 승인
→ 실행 결과 평가
```
