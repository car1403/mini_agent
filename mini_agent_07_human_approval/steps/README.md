# Human Approval Steps

강의 메뉴 7-1부터 7-6까지 같은 번호의 파일을 실행합니다.

```powershell
python .\01_action_risk.py
python .\02_allowlist_and_ownership.py
python .\03_pause_save_resume.py
python .\04_langgraph_interrupt.py
python .\05_approve_and_reject.py
python .\06_safe_execution.py
```

`04_langgraph_interrupt.py`만 LangGraph가 필요합니다. 나머지는 표준 Python 예제이므로 정책과 승인 흐름을 먼저 가볍게 연습할 수 있습니다.

예제를 모두 이해한 뒤 `backend_langgraph`와 `frontend` 완성본에서 같은 개념이 화면과 API로 연결되는 과정을 확인합니다.
