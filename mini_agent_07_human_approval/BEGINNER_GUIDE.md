# 07 초보자 가이드 · Human Approval과 Safety

처음부터 `interrupt()` 문법을 외우지 않습니다. 먼저 “무엇을 왜 멈춰야 하는가”를 일반 Python으로 이해합니다.

```text
7-1 위험도 구분
→ 7-2 실행 권한 검사
→ 7-3 일반 Python으로 중단·저장·재개
→ 7-4 LangGraph interrupt로 교체
→ 7-5 승인·거절 검증
→ 7-6 승인 후 한 번만 Mock 실행
```

## 반드시 구분할 네 가지

- **중단**: 변경 작업 직전 실행을 멈춥니다.
- **저장**: 어디까지 처리했는지 상태를 남깁니다.
- **재개**: 같은 실행에 승인 또는 거절 데이터를 전달합니다.
- **실행**: 정책과 승인을 모두 통과했을 때만 변경 작업을 수행합니다.

## 가장 중요한 경계

```text
사용자 문장 / LLM 제안 = 신뢰하지 않는 입력
allowlist / 소유자 / 위험도 검사 = 시스템 정책
```

“이미 승인받았다”는 문장이 입력에 있어도 실제 저장 상태와 승인자를 검사합니다. Prompt Injection 문구를 전부 찾기보다, 어떤 문장이 와도 같은 코드 정책을 통과하게 만드는 것이 핵심입니다.

## LangGraph에서 주의할 점

- checkpointer를 설정합니다.
- 시작과 재개에 같은 `thread_id`를 사용합니다.
- 재개 값은 `decision`, `actor`, `note`로 구조화합니다.
- `interrupt()` 앞에는 예약·결제 같은 Side Effect를 두지 않습니다.
- 재시도나 중복 요청에도 한 번만 실행되도록 `request_id`를 기록합니다.

이 과정에서는 실제 외부 서비스를 호출하지 않고 Mock 실행까지만 다룹니다.
