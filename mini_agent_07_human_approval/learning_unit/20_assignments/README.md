# 07 Assignment · 병원 예약 승인 Agent

병원 예약 요청을 안전하게 처리하는 작은 프로그램을 만드세요.

## 정책

| 작업 | 정책 |
|---|---|
| 병원 정보 조회 | 자동 허용 |
| 예약 가능 시간 조회 | 자동 허용 |
| 예약 요청서 초안 | 자동 허용 |
| 본인 예약 변경 요청 | 사용자 승인 필요 |
| 다른 사용자 예약 조회·변경 | 금지 |
| 실제 결제 | 금지 |

## 필수 구현

1. Tool 이름 allowlist 검사
2. 요청 소유자와 승인자 검사
3. 조회·변경·금지 위험도 분류
4. 변경 작업의 승인 대기 상태 저장
5. 구조화된 승인·거절 데이터로 재개
6. 승인 뒤 교육용 Mock 결과 기록
7. 같은 요청의 중복 실행 차단

## 제출 시나리오

- 조회 작업 자동 완료
- 변경 작업 승인 대기
- 올바른 사용자의 승인
- 올바른 사용자의 거절
- 다른 사용자의 승인 시도 차단
- 허용되지 않은 Tool 차단
- 동일 요청 재실행 차단

## 완료 기준

- LLM 또는 사용자 문장만으로 정책을 우회할 수 없습니다.
- 거절·금지 작업에서는 변경 결과가 생성되지 않습니다.
- 실제 병원 예약이나 결제 API를 호출하지 않습니다.
- 실행 결과에 상태, 처리자, 이유 또는 메모를 남깁니다.
