# Starter

1. `mcp_server/travel_server.py`에 날씨 Tool을 선언합니다.
2. MCP Server를 Streamable HTTP 방식으로 8010 포트에 실행합니다.
3. Backend에서 Streamable HTTP Client로 서버에 연결합니다.
4. `list_tools()` 결과로 호출 가능한 Tool을 확인합니다.
5. `call_tool()` 결과를 API 응답 Trace에 포함합니다.
6. Frontend에서 연결 상태, Tool Call과 Tool Result를 구분해 표시합니다.
